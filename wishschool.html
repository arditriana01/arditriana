EDUCATION WEBSITE

WISH School

Redesigning a preschool and kindergarten website to improve user experience, information clarity, and parent engagement.

Visit Website

Overview

Wish School is an early childhood education institution in Denpasar, Bali that focuses on combining local values with global educational standards.

The school provides multiple educational programs for children aged 2–6 years including daycare, nursery, preschool, and kindergarten.

  • Daycare (2-6 years)
  • Nursery (2-3 years)
  • Preschool (3-4 years)
  • Kindergarten A & B (4-6 years)

The main audience includes young parents, professional families, and parents seeking character-based education in Bali.

Role

WordPress Developer

Timeline

2-3 Weeks

Stack

WordPress, Elementor, PHP

The Challenge

The existing website had several usability and structure issues that made it difficult for parents to quickly understand the school programs and enrollment process.

  • Information structure was unclear
  • Poor content hierarchy
  • Lack of conversion-focused CTA
  • Weak emotional storytelling
  • Mobile experience needed improvement

My Solution

Clear Program Structure

Organized the website into clear educational programs based on student age groups.

Better User Experience

Redesigned the navigation and layout to improve readability and accessibility.

Mobile Optimization

Built a fully responsive experience optimized for mobile-first users.

Development Process

01

Research

I analyzed several important aspects before starting the redesign process:

  • International preschool websites
  • Education landing page structures
  • Parents behavior when searching for schools
Main Insight

Parents usually do not read long paragraphs. They scan for important information quickly.

02

Wireframing

I created the homepage structure based on user behavior and content priority.

Hero About School Programs Facilities CTA Contact
03

WordPress Development

The website was developed using modular and scalable components.

  • Elementor for layout flexibility
  • Reusable section components
  • Responsive mobile-friendly structure
04

Performance Optimization

  • Lazy loading implementation
  • LiteSpeed cache optimization
  • CDN integration

Key Features

Program-Based Navigation

Parents can directly select educational programs based on their child's age.

Clear Information Hierarchy

Important information is structured clearly from age, curriculum, activities, to tuition cost.

Mobile-First Design

The interface is optimized for mobile users because most parents access the website through smartphones.

Inquiry Funnel

Users can directly contact the school via contact form, WhatsApp, or visit scheduling.

SEO Structure

Implemented heading hierarchy, internal linking, and metadata optimization for better discoverability.

Technical Challenges

Challenge

Displaying a large amount of information without making the website feel crowded.

Solution
  • Using proper sectioning and whitespace
  • Accordion components for detailed information
  • Modular content layout

Result & Impact

The redesigned website provides a more professional and engaging digital experience for parents looking for early childhood education programs.

  • Improved information clarity
  • Better mobile responsiveness
  • More structured user journey
  • Stronger visual branding
  • Improved conversion flow
