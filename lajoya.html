HOSPITALITY WEBSITE

La Joya Resort Website

Designing a modern hospitality website to showcase the resort experience, improve booking accessibility, and create a more immersive user journey for travelers.

Visit Website

Overview

La Joya Balangan is a boutique resort located in South Bali. The resort offers handcrafted villas with ocean views and a relaxing tropical atmosphere.

The business mainly targets international travelers looking for romantic getaways and quiet vacation experiences.

The resort already had a website, but it was outdated and did not effectively convert visitors into bookings.

Role

WordPress Developer

Timeline

2-3 Weeks

Stack

WordPress, Elementor, PHP, LiteSpeed Cache

Technical Challenges

Challenge

One challenge was handling large villa images without sacrificing visual quality.

Solution
  • Images were converted to WebP format
  • Lazy loading was implemented
  • A CDN was used to deliver images faster globally

My Solution

To solve these problems, I developed a modern WordPress website designed specifically for early childhood education institutions. The new website focuses on clear communication, engaging visuals, and a smoother user journey for parents exploring the school programs.

Clear Program Structure

Organized educational programs into clear categories based on children's age groups to help parents quickly find relevant information.

Better User Experience

Redesigned the navigation, content hierarchy, and visual layout to improve readability and simplify the enrollment journey.

Mobile Optimization

Built a fully responsive experience optimized for mobile and tablet users since most parents access the website through smartphones.

Performance Optimization

Optimized images, implemented caching, and improved overall website performance to achieve faster loading speed and smoother browsing.

SEO & Inquiry Flow

Applied SEO best practices and created clear call-to-action sections to help parents easily contact the school and schedule visits.
